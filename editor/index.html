❓ Как пользоваться

            
        

        

            
Что это

            
Редактор правил доступа к сайтам. Здесь настраивается: какие сайты доступны, где, когда, на сколько минут.


            
3 шага

            
    
                
  1. Места — добавьте точки (Дом, Работа) с координатами и радиусом
    2. 
                
  2. Временные окна — добавьте расписания (Будни 9–18, Вечер)
    3. 
                
  3. Сайты — добавьте сайты и выберите, где и когда они открываются
    4. 
            


            
Как сохранить

            
    
                
  1. Нажмите 📤 Сохранить — скачается rules.json
    2. 
                
  2. Откройте GitHub → access/rules.json → ✏️ Edit
    3. 
                
  3. Вставьте новый JSON → Commit changes
    4. 
                
  4. Через 1–2 минуты правила применятся
    5. 
            


            
Пароли

            
В форме сайта есть раздел «Пароль». Введите:

            
    
                
  • Основной пароль — откроет настоящий сайт
    • 
                
  • Подставной пароль — откроет decoy-сайт (например, «Погода»)
    • 
            

            
Так, если кто-то заставит вас ввести пароль — вводите подставной, и он увидит безобидный сайт.


            
Интервальный доступ

            
Можно задать: «каждые 2 часа окно 15 минут». Тогда сайт открывается 00:00–00:15, 02:00–02:15 и т.д.
